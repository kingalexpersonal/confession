# confession 

A digital confession wrapped in a **Chelsea FC x Liquid Ink** theme. 

This interactive web experience features a unique **drag-to-unlock** mechanic. Users must drag a physical key from the bottom of the screen to a central lock to trigger a fluid "ink splash" animation, revealing a hidden, scrollable letter.

## 🎨 The Vibe
- **Theme:** Minimalist Black & White with Chelsea Blue (`#034694`) accents.
- **Visuals:** Subtle floating particles, liquid ink transitions, and a clean grid-paper aesthetic.
- **Interaction:** No buttons. Just drag, unlock, and read.
- **Content:** A heartfelt, personal message with interactive "hidden text" reveals on hover/tap.

## 🚀 Live Demo
https://kingalexpersonal.github.io/confession/

## 🛠️ Features
- **Drag & Drop Unlock:** Custom touch/mouse event handling for a seamless mobile and desktop experience.
- **Liquid Animation:** CSS transitions simulating an expanding ink drop upon unlocking.
- **Interactive Text:** Hover or tap specific underlined sections to reveal hidden thoughts.
- **Responsive Design:** Optimized for mobile screens but works perfectly on desktop.
- **Zero Dependencies:** Pure HTML, CSS, and Vanilla JavaScript. No frameworks required.
